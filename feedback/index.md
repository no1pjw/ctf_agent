# CTF feedback index

분야별 풀이 스킬은 처음에 해당 분야의 `index.md`만 읽고, 현재 증상과 일치하는 주제 문서만 추가로 읽는다.

- pwn: `../pwn-agent/feedback/index.md`
- reverse engineering: `../rev-agent/feedback/index.md`
- web: `../web-agent/feedback/index.md`
- crypto: `crypto/index.md`
- forensics, misc, OSINT, malware, AI/ML: `forensics/index.md`

새 교훈은 `ctf-learn <문제이름>`으로 검토한다. 분야 메타데이터가 없는 수동 문제는 `--category`를 지정한다.
