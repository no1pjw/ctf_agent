# Playbook

1. Record scope, origin, state reset, accounts, source revision, and runtime.
2. Map endpoints, methods, roles, state transitions, and trust boundaries.
3. Trace attacker-controlled data through validation, storage, and sinks.
4. Rank hypotheses by likelihood, impact, and test cost.
5. Send a baseline, one controlled mutation, and a negative control.
6. Explain the violated security invariant and derive the flag path.
7. Reproduce from clean state. Keep only the final exploit and concise write-up unless audit mode is requested.
