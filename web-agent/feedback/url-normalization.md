# URL 정규화·다중 디코딩

## 중첩 percent-encoding에 따른 필터/애플리케이션 해석 차이

- **증상:** 평문이나 한 번 인코딩한 쿼리 값과 달리, 같은 의미를 중첩 percent-encoding한 값만 보호된 동작에 도달한다.
- **재사용 가능한 교훈:** 앞단 검사가 원시 문자열 또는 한 번 디코딩한 값을 검사하고 뒤 계층이 다시 디코딩하면, 계층마다 비교하는 값이 달라질 수 있다. 입력 검증과 권한 판단은 라우팅·파싱이 끝난 하나의 canonical 값에 대해 수행해야 한다.
- **가장 싼 확인법:** 무해한 식별자 하나를 평문, 1회 인코딩, 2회 인코딩으로만 바꿔 보내고 상태 코드·리다이렉트·응답 표식의 차이를 비교한다. 다른 파라미터와 세션은 고정한다.
- **환경/적용 한계:** 프록시, WAF, 웹 서버, 프레임워크가 percent-encoding을 거부하거나 동일 횟수로 정규화하면 성립하지 않는다. 차이만으로 권한 우회를 단정하지 말고, 동일 세션의 음성 대조군과 실제 보호 동작을 함께 확인한다.
