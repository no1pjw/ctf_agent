# Web reference

## Map

Document routes, methods, roles, sessions, object ownership, parsers, templates, storage, queues, browser origins, and outbound requests.

## Test themes

Authorization transitions, server/client validation gaps, injection sinks, file handling, deserialization, race/state machines, cache/proxy interpretation, and browser trust boundaries.

Use source-first local tests. For an explicitly allowed remote challenge, send minimal requests only to the recorded origin and preserve controls.
