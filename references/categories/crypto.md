# Crypto reference

## Reconstruct first

Write down primitive, mode/construction, parameters, encoding, padding, nonce/IV generation, key relationships, oracle, and attacker-known values.

## Check before search

Nonce reuse, weak randomness, small parameters, linearity, malleability, invalid validation, related keys/messages, partial leakage, biased output, algebraic structure, and implementation/encoding mistakes.

Implement a verifier and use known-answer plus negative tests. Bound any search and checkpoint it.
