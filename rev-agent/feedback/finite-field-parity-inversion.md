# Finite-field parity inversion

## 패리티 검증식을 원문 미지수의 선형계로 바꾸기

- 증상: 검증기가 입력 뒤에 고정 패리티를 붙인 codeword를 만들고, GF(2^8)에서 여러 평가점의 syndrome이 모두 0인지 확인한다.
- 재사용 가능한 교훈: 각 syndrome 식에서 알려진 패리티 항을 우변으로 옮기면 원문 바이트만 미지수인 유한체 선형계가 된다. 평가점의 거듭제곱을 계수로 구성하고 같은 체의 덧셈(XOR), 곱셈, 역원으로 가우스 소거하면 오류 정정 디코더 전체를 구현하지 않고도 원문을 직접 복원할 수 있다.
- 가장 싼 확인법: 한 평가점에서 복원한 계수와 고정 패리티를 원래 순서로 다시 평가해 syndrome 0을 확인한다. 이후 모든 평가점에 같은 정방향 검사를 assertion으로 적용한다.
- 환경/적용 한계: 생성다항식, 계수 순서, 평가점 시작값이 하나라도 다르면 일관된 듯한 오답이 생길 수 있다. 먼저 지수표가 0이 아닌 모든 원소를 중복 없이 순회하는지와 다항식 reduction 규칙을 확인하고, 행렬이 singular이면 순서·평가점 가정을 재검토한다. 오류 위치까지 미지수이거나 검증기가 비선형 후처리를 섞으면 이 직접 선형화만으로는 충분하지 않다.
