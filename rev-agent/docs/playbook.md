# Playbook

1. Inventory format, architecture, sections, imports, strings, and entropy without calculating checksums.
2. Locate input, validation, transformation, and success paths.
3. Rename from evidence and maintain a function/data map.
4. Select a profile: native, bytecode/VM, loader/packer, or obfuscation.
5. Use breakpoints or traces only to answer a written question.
6. Recover constants and transformations into a standalone solver.
7. Compare solver output with the target and a negative input.
