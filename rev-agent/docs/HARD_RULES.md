# Hard rules

- Never execute original or copied challenge artifacts on the host.
- Never enable runtime networking or contact an external target for a local reversing problem.
- Never browse for a write-up, solution, repository, or challenge-specific hint.
- Never disable containment because analysis is difficult.
- Never calculate or require SHA-256 checksums.
- Never claim success from a string that merely resembles a flag.
- Never use unbounded brute force or leave an unmanaged long-running process.
- Preserve architecture, loader, runtime, signedness, width, and endianness assumptions.
